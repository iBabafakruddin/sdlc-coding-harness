# Skill: React & Modern Frontend Patterns
- Build small, focused functional components with strict TypeScript props interfaces.
- Separate server-state fetching (TanStack Query / SWR / custom hooks) from presentational UI components.
- Avoid unnecessary `useEffect` hooks for derived state; compute derived values during render or with `useMemo` when expensive.
- Handle `loading`, `error`, and `empty` states explicitly in every data-driven view.
