# Skill: Angular Standalone & Signals Patterns
- Use `standalone: true` components, `ChangeDetectionStrategy.OnPush`, and the `inject()` function instead of constructor DI.
- Use Angular Signals (`signal()`, `computed()`, `input()`, `output()`) for synchronous reactive UI state and RxJS for async event streams.
- Use built-in control flow syntax (`@if`, `@for (...; track item.id)`, `@switch`) in templates and reactive forms (`FormBuilder`, strict typing).
